Add copy/paste for Petri net elements. Select one or more elements (use Ctrl/Shift+click for multiple) and copy with Ctrl+C or the toolbar button, then paste duplicates with Ctrl+V. Pasted elements include arcs between copied nodes, keep labels and tokens, are anchored near the viewport center, and can be pasted into any open net tab. Paste is a single undoable action.
