Re-work canvas interaction in selection mode. Left-click still selects a single element, and left-button drag-and-drop on a node still moves it, but left-button drag on the empty canvas now rubber-band (box) selects any elements inside the dragged rectangle. Panning the canvas is now done exclusively by dragging with the middle mouse button instead of the left button.
